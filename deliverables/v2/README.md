# CBP V2 — 회수예약표

**먼저 `cbp-main-v2.pdf`를 보세요.** 이번 버전은 하나의 장면으로 시작해 예약표, 도착 시간축, 탄소예산, 실패 대응을 설명합니다.

> 파렛트가 급해지기 전에 재고·차량 빈칸·탄소를 함께 예약하고, 마지막 안전 시각에 실제 도착량을 확인해 부족분만 대체 회수한다.

## 이번에 바꾼 점

- ‘프레임워크’라는 추상적 설명을 **회수예약표**라는 눈에 보이는 대상으로 바꿨습니다.
- 재고·빈칸·탄소를 함께 예약하는 이유를 분리해서 보여줍니다.
- **160매, 16시 필요, 14시 대체회수 마감**이라는 동일한 예시를 끝까지 사용합니다.
- 예약 수량과 실제 입고량이 다를 때 어떻게 대응할지 보여줍니다.
- 숫자로 효과를 과장하지 않고, 정상·불가능·비용 증가 상황을 구분했습니다.

## 확인된 것

메인 6장 / 배너 4쪽 / Q&A 3장, 배너와 메인 2~5장의 내용 동일성, 발표자 노트, 슬라이드 경계와 렌더링을 확인했습니다. 계산 코드에서 탄소예산·비용 상한·부족 수량·대체재고·대체차량·마감 초과 상황 및 161개 수량 입력을 확인했습니다.

검증은 합성 입력의 산술과 규칙 검증입니다. 현장 운영 또는 감축 효과 실증이 아닙니다. 독창성은 추가 선행기술·현장 조사가 필요합니다.

## 사용 시 참고

PPT의 주요 도식과 글자는 편집 가능합니다. 사용 글꼴은 **Noto Sans CJK KR**입니다. 다른 컴퓨터에서 글꼴이 대체되면 줄바꿈이 달라질 수 있으므로 PDF와 비교하세요.
