# 외부 조사 현황

이번 작업에서 확인한 것은 사용자 제공 예선 PPT, KPCA 합격 안내 PDF, 2025년 배너 예시, 사용자 제공 피드백 문서다. 2025 배너 예시는 수상 순위나 심사 근거가 확인된 수상작 데이터베이스가 아니다.

외부 조사 경로로 Crossref, OpenAlex, Semantic Scholar, arXiv, KPCA, Google, Smart Freight Centre, ISO를 시도했다. 일반 네트워크 권한이 부여된 뒤 다시 요청했지만 환경 프록시가 `403 Forbidden`으로 차단했다. `access_log.json`에 재시도 결과를 남겼다. **검색 결과나 논문 원문을 읽지 못했으므로, 이 경로의 연구 제목·저자·성과를 확인된 참고문헌으로 제시하지 않는다.**

환경 설정의 개발 사이트 허용 목록은 읽어서 확인했다. 기존 사용자 지정 허용 도메인은 없었고 패키지 관리자 사전 설정이 활성화되어 있었다. 연구용으로 다음 9개 도메인을 추가하는 설정 초안을 저장했다. 저장 자체는 현재 런타임에 적용하거나 환경을 게시하지 않는다. 사용자가 환경 설정에서 검토·저장 후 게시해야 적용된다.

`www.google.com`, `api.crossref.org`, `api.openalex.org`, `api.semanticscholar.org`, `export.arxiv.org`, `www.kopal.or.kr`, `www.smartfreightcentre.org`, `www.iso.org`, `doi.org`

## 접근 가능해지면 확인할 질문

| 연구 축 | 검색어 예시 | 확인할 내용 |
|---|---|---|
| 파렛트 풀링·빈 자산 재배치 | pallet pooling repositioning carbon emissions optimization | 기존 의사결정 단위, 재고·적재·기한·배출 제약 |
| 재사용 운송 포장 | reusable transport items pooling carbon footprint | ULS 자산 생애주기와 운송 배출 산정 범위 |
| 동적 가중치 | dynamic adaptive weights multi criteria logistics carbon budget | 상태에 연동한 가중치가 이미 연구됐는지 |
| 예산 기반 온라인 운영 | carbon budget online decision making logistics | 현재 사용량뿐 아니라 남은 시간·수요를 반영하는 방식 |
| 물류 배출 회계 | GLEC Framework ISO 14083 transport chain emissions | 거리·연료·적재·공차 배출의 동일 경계 산정 |
| 공모전 선례 | 유닛로드시스템 창의성 공모전 수상작 KPCA | 공식 발표 자료, 수상 순위, 심사 기준 원문 |

## 조사 결과를 기록할 형식

논문/자료명, 저자/기관, 연도, DOI/공식 URL, 읽은 범위(초록/원문), 의사결정 대상, 탄소예산 상태 사용 여부, 가중치 조정 여부, 제약조건, 데이터 종류, CBP와 겹치는 부분, 차이, 아직 확인하지 못한 부분을 표로 작성한다.

초록만 읽었다면 알고리즘의 세부 구현이 없다고 단정하지 않는다. 정확히 같은 구조를 발견하면 신규성 주장을 줄이고 ULS 적용 범위·운영 조건·실증 설계의 기여로 재정의한다. 시장이나 기관의 기존 시스템을 ‘탄소 측정만 한다’고 묘사하지 않는다.
